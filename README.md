# Curso: IA Para Devs | Plataforma: Rocketseat

Este é um repositório com foco exploratório e didático baseado no curso "IA para Devs" da plataforma Rocketseat. O objetivo principal é o estudo e a prática de diversos conceitos fundamentais no ecossistema de Inteligência Artificial.

## Conteúdos Abordados

*   **Introdução à IA**: Conceitos fundamentais de Inteligência Artificial.
*   **Bots e Chatbots**: Princípios de funcionamento e criação de interfaces conversacionais.
*   **Plataformas de IA Conversacional**:
    *   IBM Watson
    *   Google Dialogflow
*   **Modelos de Linguagem**:
    *   OpenAI (GPT e ferramentas relacionadas)
    *   O que são e como funcionam os LLMs (Large Language Models)
    *   BERT (Bidirectional Encoder Representations from Transformers)
*   **Arquiteturas RAG (Retrieval-Augmented Generation)**:
    *   Conceitos básicos de RAG
    *   Parent RAG
    *   Compressor RAG (Rerank)
*   **Ecossistema e Ferramentas Cloud**:
    *   Google Colab (para experimentação rápida)
    *   AWS Bedrock
    *   Deploy de modelos e aplicações de IA
*   **Aprimoramento de Modelos**:
    *   Fine-tuning (Ajuste fino) de LLMs
*   **Agentes de IA Autônomos**:
    *   Conceitos e criação de Agentes de IA
    *   CrewAI
    *   AutoGen Studio
*   **Prompt Engineering**: Técnicas e melhores práticas para interagir de forma eficiente com modelos de linguagem.
